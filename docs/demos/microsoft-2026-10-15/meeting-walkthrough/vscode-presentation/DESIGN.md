# Microsoft meeting presentation design

Use the approved DICE company-colour treatment from the meeting's existing showcase design brief.

| Role | Colour |
| --- | --- |
| Paper | `#F4F3EE` |
| White | `#FFFFFF` |
| Ink | `#1C1C1C` |
| Grey | `#5A5D5C` |
| Sand | `#CCCABC` |
| Signal red | `#E60000` |

Use Arial/Helvetica, square diagram nodes, thin rules and red connection lines. Keep the diagrams open and readable beside annotated YAML. Preserve the same artwork in HTML, Markdown and the locally generated PDF. Do not add employer logos or private environment values.

The slides use generic agent terminology and retain agentgateway. Source YAML keeps its actual API identifiers. Notes distinguish configuration patterns, repository POCs, recorded evidence and proposed durable-agent work.
