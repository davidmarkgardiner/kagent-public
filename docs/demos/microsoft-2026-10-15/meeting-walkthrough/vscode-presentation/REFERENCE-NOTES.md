## Denodo integration

The local Denodo FastMCP/UAMI bundle describes typed read-only tools over approved VDP views using JDBC. Identity, JDBC driver, TLS trust, network access, and a real UAMI canary are separate prerequisites. Its synthetic driver contract is not live Denodo proof.

The underlying work bundle is separate from this presentation publication. This note preserves the slide's limited claim without linking to unpublished files or implying that the slide installs that integration. PostgreSQL and Denodo are separate adapters; the PostgreSQL tool names in the catalogue do not describe Denodo's tool API.
