One safe delivery, end to end.

The proof of concept keeps Buzz as the signed human-facing thread and kagent as the bounded worker plane. It demonstrates a request, a pause for approval, a same-task resume, and a review-only delivery receipt.

POC verified — human review remains the merge authority

The path that was proven

1. Buzz requestA private, signed task event starts one bounded delivery.
2. Durable bridgeSQLite records the source event, A2A context, task ID, and state. Replays are deduplicated.
3. kagent workersCoordinator → builder → verifier → documenter. No shell, Git-write, Kubernetes-write, or merge tools.
4. Approval pauseThe deterministic fixture returns A2A input-required; the bridge posts a threaded approval request.
5. Evidence gateA clean SHA, direct tests, and an existing draft PR produce a review-only receipt.

What the live approval proof did

1
Created a disposable private Buzz channelThree temporary identities: bridge, requester, and approver.
2
Sent a structured taskThe bridge forwarded it to the isolated A2A fixture and persisted the correlation.
3
Received an approval requestThe fixture returned input-required; Buzz received sdlc.approval_required in the source thread.
4
Approved in the same threadA threaded approve decision resumed the exact stored A2A task — it did not create a replacement task.
5
Finished and cleaned upThe resumed task ended completed; the temporary channel and identities were removed.

What it deliberately does not do

No autonomous mergeThe gate says ready_for_human_review: true but always merge_eligible: false.
No hidden agent powerRole agents cannot run arbitrary shell, change Git, write Kubernetes, or create merges.
No runaway loopOne task is handled at a time; a follow-up is proposed explicitly rather than silently injected.
