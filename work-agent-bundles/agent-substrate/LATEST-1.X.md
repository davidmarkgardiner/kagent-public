# New kagent 1.x evaluations

For the 18 November 2026 documentation and lab refresh, start at the [current handbook](../agent-platform-mkdocs/README.md) and [new lab profile](../agent-platform-mkdocs/labs/kagent-1.0.1/README.md).

The existing files in this bundle retain their historical compatibility pins and evidence. Do not turn a 0.x `SandboxAgent` installer into a 1.0 install by changing tags. kagent 1.0.1 uses a new API and pins Substrate 1.0.0. The new profile also renders the latest standalone Substrate 1.0.1 as a separate candidate; neither pairing has fresh live acceptance in this refresh.

Runtime acceptance remains pending in the intended environment. Follow the new profile's preflight, migration and L01–L12 gates before claiming a validated runtime. The workplace policy blocker remains open.
