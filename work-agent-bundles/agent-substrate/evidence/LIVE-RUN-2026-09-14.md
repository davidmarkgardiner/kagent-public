## What this proves

- The current SandboxAgent manifest reconciles on the installed API version.
- The generated actor can resume, run and suspend.
- A later request can restore the same actor and retain functional session state.
- A different session creates a different actor and did not inherit the marker in this test.

## Boundaries

- This checks functional separation between these two synthetic sessions. It is not a complete tenant-isolation or security proof.
- Suspension is not deletion. Snapshots and session data require separate retention and erasure controls.
- No performance, density, cost saving or production-scale result was measured.
- The public short may describe enterprise kagent experience, but this footage must be labelled as a sanitized reconstruction and must not be presented as a customer production environment.
- Employer, customer, private endpoint, cluster, subscription and repository identifiers are excluded from this receipt.
