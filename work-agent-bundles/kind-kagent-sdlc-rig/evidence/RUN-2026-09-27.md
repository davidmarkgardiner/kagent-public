# Supervised home-lab canary — 2026-09-27

## Scope and source

This was one Proxmox Kubernetes cluster, one Kimi ModelConfig, one private
GitLab sandbox project, and the bundle from draft [PR #102](https://github.com/davidmarkgardiner/kagent-public/pull/102)
at `d54ca1a6`. It was a home-lab rehearsal, not a workplace install or an
unattended production qualification. The lab profile explicitly allowed the
control-plane node because the two restored workers had insufficient schedulable
room for the rig. The installed board CronJob used a two-minute schedule.

Before the canary, the sandbox project's human-owned `main` gained a CI job
that calls `node --test tests/` directly, and a test fixture. Its
[main pipeline 2887442610](https://gitlab.com/davidmarkgardiner/debt-payoff-calculator-agentic-factory/-/pipelines/2887442610)
passed. The builder's allowed paths exclude `.gitlab-ci.yml`. The rendered
bundle was applied with board polling suspended while the manual checks ran.

The bundle's 28 offline tests passed. The example profile rendered cleanly.
The live preflight passed against the applied lab stack. All five Agent CRs
were Accepted and Ready; the PM echo nonce returned through the worker in a
real A2A turn. These checks establish a working route, not the correctness of
arbitrary generated work.

## Remaining limits

- The forged PASS note guard passed offline regression tests, but was not
  exercised as a separate live GitLab case.
- The timed-out PM case shows the original task continues after the caller
  disconnects. Durable task IDs and task status checks are still needed for
  unattended retries. A5 remains open.
- The accepted issue proves orchestration and evidence gates for a small README
  change. It does not establish general software quality or workplace readiness.
- Production hardening tasks B1–B12 in `REVIEW-TASKS.md` remain open. In
  particular, one malformed issue can abort a poll, CI can wait indefinitely,
  and tester evidence is not an independently checked artifact.
- The workplace cluster still needs its own model route, GitLab identity,
  policy, scheduling, trust, and canary checks. No workplace credentials or
  cluster were used here.

The Proxmox host was shut down after this rehearsal at the owner's request;
the lab stack is offline until that host is restarted. Draft MR !13 was not
merged.
