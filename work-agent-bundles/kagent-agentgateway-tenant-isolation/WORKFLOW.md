# Build workflow

This file records the run sequence. Each phase must end with evidence before the next phase starts.

1. Ground the installed and upstream API versions.
2. Compare team-local and centralized platform-object designs.
3. Write the platform contract and offline verifier.
4. Add the event-driven team example.
5. Add the interactive chat team example.
6. Import the platform-owned Agent Substrate specialist and version contract.
7. Add the rogue namespace and negative tests.
8. Render and validate every manifest against pinned schemas.
9. Deploy the canary stack to the `red` context.
10. Capture positive, negative, and actor-lifecycle evidence.
11. Run the public-safety scan and package the handoff.

The work is complete when the bundle renders without placeholders in the local overlay, both tenant A2A-to-MCP paths and the platform Substrate A2A path work through agentgateway, every rogue path has the expected denial, the actor suspends to a new snapshot, and the evidence names any boundary that the red cluster could not prove.

Status on 2026-09-16: complete for the disposable JWT red profile. The Entra profile remains a documented AKS promotion gate because red cannot supply the workplace tenant, hostname, certificate, or workload-token broker.
